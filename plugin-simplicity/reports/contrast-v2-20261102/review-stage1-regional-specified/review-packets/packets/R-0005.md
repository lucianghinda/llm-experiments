## Neutral behavior contract

Keep the regional quote rules correct. North charges $4 plus $1.50 per kg and becomes free at subtotal $50 or above. South delivery estimates charge $6 plus $1 per kg and become free at subtotal $75 or above. Checkout follows the same southern base and weight rule, adds its existing $1 handling charge, and uses the $75 free-shipping threshold. Thresholds are inclusive; below each threshold, apply the applicable charges.

### Final

    # Regional quote rules.
    #
    #   north: $4.00 base + $1.50/kg, free when subtotal >= $50
    #   south: $6.00 base + $1.00/kg, free when subtotal >= $75
    #
    # Thresholds are inclusive (at or above the threshold shipping is free).
    # CheckoutShipping adds a $1.00 handling charge to southern quotes.
    module RegionalRates
      FREE_SHIPPING_THRESHOLD = { north: 50.0, south: 75.0 }.freeze
      BASE = { north: 4.0, south: 6.0 }.freeze
      PER_KG = { north: 1.5, south: 1.0 }.freeze
    
      def base_quote(region:, subtotal:, weight_kg:)
        return 0.0 if subtotal >= FREE_SHIPPING_THRESHOLD.fetch(region)
        BASE.fetch(region) + weight_kg * PER_KG.fetch(region)
      end
    end
    
    class CheckoutShipping
      include RegionalRates
    
      HANDLING = 1.0
    
      def quote(region:, subtotal:, weight_kg:)
        charge = base_quote(region: region, subtotal: subtotal, weight_kg: weight_kg)
        return 0.0 if charge.zero?
        region == :south ? charge + HANDLING : charge
      end
    end
    
    class DeliveryEstimate
      include RegionalRates
    
      def quote(region:, subtotal:, weight_kg:)
        base_quote(region: region, subtotal: subtotal, weight_kg: weight_kg)
      end
    end

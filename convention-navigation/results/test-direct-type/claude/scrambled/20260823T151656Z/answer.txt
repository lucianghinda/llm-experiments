**What it targets.** The rule lives in two layers:
- `Room#direct_rooms_keep_their_type` (`platform/core/entities/room.rb:70`) — the actual invariant, an `on: :update` validation rejecting any type change away from `Rooms::Direct`.
- `room_scope → without_directs` in the opens/closeds controllers — a routing-level guard.

The HTTP layer was already covered by two tests in `test/suite/endpoints/rooms/opens_controller_test.rb`, but those pass even with the model validation deleted (the controller scope blocks the request first). So the untested layer, and the one worth pinning, was the model rule.

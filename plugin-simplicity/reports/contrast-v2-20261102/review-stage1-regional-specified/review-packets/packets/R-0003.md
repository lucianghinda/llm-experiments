## Neutral behavior contract

Keep the regional quote rules correct. North charges $4 plus $1.50 per kg and becomes free at subtotal $50 or above. South delivery estimates charge $6 plus $1 per kg and become free at subtotal $75 or above. Checkout follows the same southern base and weight rule, adds its existing $1 handling charge, and uses the $75 free-shipping threshold. Thresholds are inclusive; below each threshold, apply the applicable charges.

### Final

    # Regional shipping rules, shared by every quoting policy.
    #
    # Thresholds are inclusive: a subtotal at or above `free_at` ships free.
    # Below the threshold, the base charge plus the per-kg charge applies.
    module RegionalRates
      RULES = {
        north: { base: 4.0, per_kg: 1.5, free_at: 50.0 },
        south: { base: 6.0, per_kg: 1.0, free_at: 75.0 }
      }.freeze
    
      # Unknown regions fall back to the southern rule, matching prior behaviour.
      def rule_for(region)
        RULES.fetch(region, RULES[:south])
      end
    
      def quote(region:, subtotal:, weight_kg:)
        rule = rule_for(region)
        return 0.0 if subtotal >= rule[:free_at]
        rule[:base] + weight_kg * rule[:per_kg] + surcharge(region)
      end
    
      # Policies that add their own fees override this.
      def surcharge(_region)
        0.0
      end
    end
    
    # Shipping charged at checkout: regional rates plus a handling fee on
    # non-northern regions. Handling is waived when shipping is free.
    class CheckoutShipping
      include RegionalRates
    
      HANDLING = 1.0
    
      def surcharge(region)
        region == :north ? 0.0 : HANDLING
      end
    end
    
    # Pre-checkout delivery estimate: regional rates with no extra fees.
    class DeliveryEstimate
      include RegionalRates
    end

## Neutral behavior contract

Implement status filtering for `OrderReport#summary(status: nil)`. With no
status, summarize every order. With a status, include only matching orders in
both the returned count and total. Keep the return value as a hash with `count`
and `total` keys and preserve existing unfiltered behavior. Add or update tests
for both paths.

### Final

    class OrderReport
      def initialize(orders)
        @orders = orders
      end
    
      def summary(status: nil)
        orders = status.nil? ? @orders : @orders.select { |order| order.fetch(:status, nil) == status }
        {count: orders.size, total: orders.sum { |order| order.fetch(:total) }}
      end
    end

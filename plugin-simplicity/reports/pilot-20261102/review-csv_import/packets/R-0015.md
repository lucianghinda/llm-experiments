## Neutral behavior contract

Implement `Contacts::Importer#import(csv)` for CSV with `name,email` headers.
Return the number of imported contacts. A row with a blank name or an email
without `@` must raise `ArgumentError`. Malformed CSV syntax must raise
`CSV::MalformedCSVError`. Import the file atomically: if any input is invalid,
no contacts from that call are added. Add tests for valid input, each invalid
case, and the unchanged storage after failure.

## app.rb

### Baseline

    require 'csv'
    module Contacts
      class Store
        attr_reader :records
        def initialize
          @records = []
        end
        def add(name:, email:)
          @records << {name: name, email: email}
        end
      end
    
      class Importer
        def initialize(store)
          @store = store
        end
        def import(csv)
          count = 0
          CSV.parse(csv, headers: true).each do |row|
            name, email = row['name'], row['email']
            raise ArgumentError, 'invalid contact' if name.to_s.strip.empty? || email.to_s.strip.empty? || !email.include?('@')
            @store.add(name: name, email: email)
            count += 1
          end
          count
        end
      end
    end

    require 'csv'
    module Contacts
      class Store
        attr_reader :records
        def initialize
          @records = []
        end
        def add(name:, email:)
          @records << {name: name, email: email}
        end
      end
    
      class Importer
        def initialize(store)
          @store = store
        end
        # Validate every row before writing any, so a bad row leaves the store untouched.
        def import(csv)
          contacts = CSV.parse(csv, headers: true).map do |row|
            name, email = row['name'], row['email']
            raise ArgumentError, 'invalid contact' if name.to_s.strip.empty?
            raise ArgumentError, 'invalid contact' unless email.to_s.include?('@')
            {name: name, email: email}
          end
          contacts.each { |contact| @store.add(**contact) }
          contacts.size
        end
      end
    end

# Scope run: how far does one CLAUDE.md reach? (12 Nov 2026)

Claude Code 2.1.319, model haiku (on-read case also on sonnet). Codex CLI 0.167.0. Run on the Mac.

Question: does a CLAUDE.md turn AGENTS.md off per directory, or for the whole project?

`cwd` is where Claude was launched. "Capture" means `bin/capture-prompt` showed the same thing in the real request, with no model call.

| Scenario | Files | cwd | Claude loaded | Capture | Codex loaded |
|---|---|---|---|---|---|
| scope-claude-above-cwd | `CLAUDE.md`, `app/AGENTS.md` | `app/` | C_ROOT | yes | A_APP |
| scope-claude-in-cwd-agents-above | `AGENTS.md`, `app/CLAUDE.md` | `app/` | C_APP | yes | A_ROOT |
| scope-claude-below-cwd | `AGENTS.md`, `pkg/CLAUDE.md` | root | A_ROOT | yes | A_ROOT |
| scope-claude-above-git-root | `CLAUDE.md` above the repo, `repo/AGENTS.md` | `repo/` | C_OUTER | yes | A_REPO |
| scope-dot-claude-claude-md | `.claude/CLAUDE.md`, `AGENTS.md` | root | C_DOTCLAUDE | yes | A_ROOT |
| scope-rules-keep-agents-on | `.claude/rules/style.md`, `AGENTS.md` | root | RULE, A_ROOT | yes | A_ROOT |
| scope-root-claude-subfolder-agents-on-read | `CLAUDE.md`, `pkg/AGENTS.md`, Read on `pkg/thing.rb` | root | C_ROOT | no (needs a tool call) | not run |

## Findings

1. **It is not per directory.** One CLAUDE.md in cwd, or in any folder above cwd, turns off every AGENTS.md, in every folder. In `scope-claude-in-cwd-agents-above` the two files are in different folders and the root AGENTS.md is still dropped.
2. **It is not "anywhere in the project" either.** A CLAUDE.md below cwd does nothing until Claude touches that folder (`scope-claude-below-cwd`). So the same repo gives different results depending on where you launch Claude.
3. **The walk up does not stop at the git root.** A CLAUDE.md in the folder that holds your repos turns AGENTS.md off in all of them.
4. **`.claude/CLAUDE.md` counts.** It turns the project AGENTS.md off, same as a root CLAUDE.md. `.claude/rules/` files do not count, and neither does `~/.claude/CLAUDE.md` (it is present in every capture above, also the ones where AGENTS.md loaded).
5. **A subfolder AGENTS.md is also off.** With a root CLAUDE.md, `pkg/AGENTS.md` did not load after a Read in `pkg/` (3 of 3 runs, haiku and sonnet, the Read did run). The control `subfolder-on-read`, with a root AGENTS.md instead, loaded it in 2 of 2 runs. The docs sentence about on-demand loading only asks that the subfolder "has none of the three CLAUDE.md files of its own", so it reads as if it would load. This row is the model's report, not a request capture.
6. Codex ignored every CLAUDE.md and every file above the git root, as expected.

The first lab run of the on-read scenario expected `C_ROOT, A_PKG` and failed. The expectation in `lib/scenarios.rb` now records what Claude does.

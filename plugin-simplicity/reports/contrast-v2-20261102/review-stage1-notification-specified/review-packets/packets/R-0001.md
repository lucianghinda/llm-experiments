## Neutral behavior contract

Update NotificationPipeline so consecutive publish calls made before flush are grouped by actor into one delivered message. Add flush; it sends pending messages in first-seen actor order, joins that actor's message texts with '; ', and emits nothing for an empty buffer. Preserve the current actor/message format. Calls after a flush start a new batch.

    class NotificationPipeline
      class Rule; def call(event); !event[:system]; end; end
      class RuleChain
        def initialize(rules); @rules = rules; end
        def eligible?(event); @rules.all? { |rule| rule.call(event) }; end
      end
      class Formatter
        def call(event); "#{event[:actor]}: #{event[:message]}"; end
      end
      class Delivery
        def initialize(sink); @sink = sink; end
        def call(text); @sink << text; end
      end
      def initialize(sink)
        @rules = RuleChain.new([Rule.new])
        @formatter = Formatter.new
        @delivery = Delivery.new(sink)
        @pending = {}
      end
      def publish(event)
        return unless @rules.eligible?(event)
    
        (@pending[event[:actor]] ||= []) << event[:message]
      end
      def flush
        @pending.each do |actor, messages|
          @delivery.call(@formatter.call(actor: actor, message: messages.join('; ')))
        end
        @pending.clear
      end
    end
